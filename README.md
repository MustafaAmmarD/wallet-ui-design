# محفظتي — تصميم واجهة المستخدم

تصميم كامل لتطبيق محفظة مالية باستخدام HTML & CSS (Static) — مرجع بصري لبناء تطبيق Flutter.

## 🚀 طريقة الاستخدام

افتح `index.html` مباشرة في المتصفح. استخدم شريط التنقل في الأسفل للتنقل بين الشاشات.

## 🗂️ هيكل الملفات

```
/
├── index.html          ← الصفحة الرئيسية مع جميع الشاشات
├── css/
│   ├── style.css       ← المتغيرات + Base styles + RTL/LTR
│   ├── components.css  ← أزرار، حقول، بطاقات، هيدر، Drawer، Bottom Sheet
│   └── screens.css     ← أنماط خاصة بكل شاشة
├── js/
│   └── app.js          ← التنقل + اللغة + Drawer + Bottom Sheet + Toggles
└── README.md
```

## ⚙️ الميزات التقنية

- **RTL/LTR**: تبديل الاتجاه عبر زر "English" في القائمة الجانبية
- **CSS Variables**: جميع الألوان والمقاسات كمتغيرات قابلة للتعديل
- **Mobile-first**: عرض ثابت 375px (iPhone size)
- **Font Awesome 6**: لجميع الأيقونات
- **Cairo Font**: خط عربي من Google Fonts
- **No dependencies**: لا حاجة لأي بناء أو تثبيت
